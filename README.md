# Petros Ndlovu — Personal Portfolio

GitHub Pages-ready personal portfolio.

## Publish
Create a GitHub repository named `petrosndlovu.github.io`, then upload:
- `index.html`
- `styles.css`
- `script.js`
- `assets/petros-ndlovu.jpg`

Enable GitHub Pages from the repository's Settings → Pages.

The portfolio is separate from PN Technologies.
